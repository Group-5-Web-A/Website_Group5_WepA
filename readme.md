# WG5WA - Group 5 Web Project

## 📖 About The Project

**WG5WA** is a team website project developed by **Group 5**.

The purpose of this project is to practice teamwork, web development, Git, and GitHub by creating a responsive website using:

* HTML5
* CSS3
* JavaScript
* Bootstrap

## 🌿 GitHub Workflow

Each member works on their own branch.

```text
main
│
├── feature/member1-home-navbar
├── feature/member2-about-team
├── feature/member3-projects
├── feature/member4-contact
└── feature/member5-css-js-testing
```

### Workflow

```text
Issue
  ↓
Create Branch
  ↓
Write Code
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Code Review
  ↓
Merge into main
  ↓
Done
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Group-5-Web-A/WG5WA.git
```

2. Open the project folder:

```bash
cd WG5WA
```

3. Open `index.html` in your browser.

## 💻 Git Commands

### Clone

```bash
git clone https://github.com/Group-5-Web-A/WG5WA.git
```

### Create a branch

```bash
git checkout -b feature/your-branch-name
```

### Check status

```bash
git status
```

### Add files

```bash
git add .
```

### Commit

```bash
git commit -m "Your commit message"
```

### Push

```bash
git push origin feature/your-branch-name
```

After pushing, create a **Pull Request** on GitHub.

## 🤝 Team Collaboration Rules

1. Do not push directly to `main`.
2. Each member works on their own branch.
3. Create a Pull Request after completing your task.
4. Another team member should review the code.
5. Test the website before merging.
6. Use clear commit messages.
7. Keep the code organized.
8. Communicate with the team before changing another member's work.

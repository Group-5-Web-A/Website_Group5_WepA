# 🌐 Team Website Project

A modern and responsive team website created as a group project using **HTML, CSS, and JavaScript**.

The website introduces our team, explains our project, showcases our work, and provides a way for visitors to contact us.

---

## 📌 Project Overview

This project is a team-based website designed and developed by **5 team members**.

The main goal is to practice:

* HTML structure
* CSS styling and responsive design
* JavaScript functionality
* Git and GitHub collaboration
* Teamwork and project management
* Website UI/UX design

---

## 🎯 Project Goals

* Create a professional and responsive website
* Practice front-end web development
* Divide tasks between 5 team members
* Learn how to work together using Git/GitHub
* Create a website that works on desktop, tablet, and mobile devices

---

## 🧭 Website Menus

The website contains **5 main menus**:

### 1. 🏠 Home

The Home page introduces the website and provides a quick overview of the project.

**Content:**

* Hero section
* Project title
* Short introduction
* Call-to-action button

### 2. 👥 About

The About page explains more about our team and project.

**Content:**

* Project introduction
* Project goals
* Project purpose
* Team information

### 3. 💻 Team

The Team page introduces all 5 members.

**Content:**

* Member photo
* Member name
* Role
* Skills
* Short description

### 4. 🚀 Projects

The Projects page displays the work created by our team.

**Content:**

* Project cards
* Project images
* Project descriptions
* Technologies used
* Project links

### 5. 📩 Contact

The Contact page allows visitors to communicate with our team.

**Content:**

* Contact form
* Email
* Social media
* Location
* JavaScript form validation

## 🔀 Git Workflow

Each team member should work on their own branch.

Example:

```bash
git checkout -b feature/home
```

```bash
git checkout -b feature/about
```

```bash
git checkout -b feature/team
```

```bash
git checkout -b feature/projects
```

```bash
git checkout -b feature/contact
```

After completing the work:

```bash
git add .
git commit -m "Add home page"
git push origin feature/home
```

Then create a **Pull Request** and merge the work into the main branch.

## 📋 Development Rules

### HTML

* Use semantic HTML5
* Keep the structure clean
* Use meaningful class names
* Add `alt` text to images

### CSS

* Keep styles organized
* Make the website responsive
* Avoid unnecessary duplicate CSS
* Use consistent colors and spacing

### JavaScript

* Use clear variable and function names
* Keep JavaScript in the `js/` folder
* Add comments when necessary
* Test interactive features before merging
